# 📊 ML Prediction Project

A simple machine learning project to predict student marks.

---

## 🛠️ Tools Used

- Python
- Pandas
- Scikit-learn

---

## 📂 Project Files

- `main.py` — Python code
- `student_data.csv` — Student data
- `model_results.csv` — Model results

---

## 🤖 ML Models

- Linear Regression
- Decision Tree

---

| Model | MAE | R² Score |
|---|---:|---:|
